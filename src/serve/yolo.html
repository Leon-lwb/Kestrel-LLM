三种推理模式 · 使用说明

模式怎么选 / 怎么开单图耗时（实测，yolov8n，cats）特点 / 边界
官方 RKNN（性能路径） 后端下拉选 rknn；模型路径给 .rknn（如 /root/_vfy/rknn_new/yolov8.rknn）；填 librknnrt.so（--rknn-lib）。保存后重启生效。 rknn_run ~16–32 ms；端到端 ~0.04–0.08 s 最快。依赖官方 .rknn（需预转）+ librknnrt（dlopen 非侵入，不改系统库）。
自研 CPU（int8 dotprod） 后端下拉选 vqf，且引擎启动 不带 --npu。保存重启。 ~144 ms 零依赖、可离线。板端实测通常比自研 NPU 直驱更快（无提交/回读开销）。
自研 NPU（VQF v4 DIRECT） 后端下拉选 vqf，且引擎启动 带 --npu。保存重启。 ~230–240 ms 零依赖；im2col→DIRECT 直驱，CPU 侧打包/提交开销较大（本板实测比自研 CPU 慢）。
切换说明：本页「传图试检测」只用所选后端临时测一张（不改常驻）；要让某模式作为常驻默认，请在「配置」卡保存（后端 vqf/rknn 落库），并按上表用引擎启动参数 --npu 与否决定「自研」走 CPU 还是 NPU，再重启引擎生效。 建议：要性能 → 走 rknn；要零依赖 → 走 vqf + 纯 CPU（~144 ms）。
