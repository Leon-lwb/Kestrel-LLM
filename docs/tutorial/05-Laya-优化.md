# 05 · Laya · 优化篇：60× 的逐级加速链，与三次「证否回退」

> 系列教程 · 第 5 篇 ｜ [返回总览](01-总览.md) ｜ 上一篇：[04 适配](04-Laya-适配.md)
> 真源：[K-LAYA-002](../立项-K-LAYA-002-G0-性能优化.md)

适配篇留下一个「不可用」的落点：板端单问题 **19.3 s**（纯标量 F32 单线程）。本篇把它降到 **0.321 s**——**60.2×**。同时它包含本系列最密集的「先微基准、后实现、证否即回退」范例。

---

## 1. 先冻结目标，再诊断

**目标**：单问题延迟 **19.3 s → ≤0.3 s**（量级），不改决策质量。

**判据（复用适配期已冻，不新造）**：

| 判据 | 内容 |
|---|---|
| J1 数值 | logits `max|Δ| ≤ 5e-3` 且 `max rel ≤ 1e-3`、argmax 与 F32 golden 一致、无 NaN |
| J2 端到端 | 与官方 `RLAgent.system_one` 逐字段一致（`choice`/argmax 必须不变） |
| J3 一致性 | 多线程 vs 单线程输出**逐位一致**（并行规约顺序不得漂移） |
| J4 覆盖 | 短(~55 tok) + 长(~512 tok 触发滑窗) 两场景 |

**瓶颈诊断（反算）**：

| 项 | 值 |
|---|---|
| 单问题 FLOPs（理论） | **~40.5 GFLOP** |
| 实测算力 | **~2.1 GFLOP/s**（= 40.5 / 19.3，纯标量 F32 无 SIMD/FMA） |
| 权重驻留 | **1.685 GB F32**（F16 源 842.6 MB，加载即展开） |
| 纯权重读取下限 | **~130 ms/问**（1.685 GB ÷ ~13 GB/s） |

⇒ **当前 compute-bound**；SIMD 把算力提上去后，**权重带宽（~130 ms）会成为次瓶颈**，量化紧随其后。

> **教学点**：这个「先 compute 后带宽」的两段式判断，决定了后续里程碑的顺序（先 SIMD，再 F16，再量化）。

---

## 2. 逐级加速链

主序按「杠杆 × 风险」：`SIMD → 去查找开销 → F16 → 多线程 → int8 → 分块 MatMul → 量化块`。**每级都在上游已过门的基线上做 diff，禁止跳级合并**。

### M1 — NEON F32 SIMD（+ 去 `lay_find`）

**改动**：`lay_dot` 双架构 SIMD（aarch64 `vfmaq_f32` 4 累加器×unroll16）；`lay_ln` 向量化；`attn_pos` 内积/加权 V 向量化；`laya_forward` **预解析** 6 类逐层权重指针，消除每位置/每层循环内的 `snprintf + lay_find` 线性扫描。

**实测**：短 state 3 问 58.0 s → **14.23 s（4.08×）**；长 state 294.9 → 76.5 s（3.85×）。

**诚实披露（估算偏差）**：原估「M1 → 1.5–2.5 s/问」**过于乐观**。反算 M1 达 **8.5 GFLOP/s ≈ 单核 A76 FP32 FMA 峰值的 48%** ⇒ 标量点积式 GEMM 已接近**单核天花板**，F32 SIMD 不可能再给 8–15×。

> **教学点**：**先算「归零上界」**——如果连单核 100% 峰值都到不了目标，就必须换维度（多线程/F16/量化）。

### M2a — F16 存储（RSS −50%，但**不提速**）

**改动**：不再把 206 张量展开成 F32 arena（1.685 GB），改为**整个 `laya_f16.bin`（843 MB）常驻 blob**；2D 权重留 F16，`lay_dot_f16` 用 `vcvt_f32_f16` **在寄存器内转 F32 后 F32 累加** ⇒ 权重值与旧 F32 arena **逐位同值**（F16→F32 无损）。1D 的 norm/bias（0.35 MB）展开进 F32 小池。

**实测**：短 state 14.23 → **15.26 s（+7%，略退化）**；**RSS 1.66 → 0.835 GB（−50%）**。

**诚实判读**：方案书的「带宽减半 → 提速」在板端**不成立**——M1 已证板端是 **compute/load-port 受限**（48% 峰值）而非带宽受限，字节减半无收益，`vcvt` 反而增 ~7%。**但 RSS 减半是实打实的收益**（边缘设备价值高，且为多线程降带宽压力）⇒ **保留**。

> **教学点**：**同一个优化在不同瓶颈档下收益符号相反**。保留的依据是「另一维度的确定收益」，而不是 headline。

### M2b — 寄存器分块（**实测 −27%，已回退**）

4 行寄存器分块（让 x 向量在 4 个输出行间复用），**16 个 NEON 累加器超出 A76 预算** ⇒ 退化 27% ⇒ **回退**。

### M4 — 位置级多线程（**最大单级收益**）

**改动**：`laya_forward` 的每个位置循环加 `#pragma omp parallel for`；共享中间张量改为**线程私有 scratch 池**（按 `omp_get_thread_num()` 取）⇒ **逐 p 计算路径与串行完全同序**。

**实测（短 state 3 问）**：

| 线程 | med | 加速 |
|---|---|---|
| OMP=1 | 15.66 s | 1.00× |
| OMP=2 @A76 | 7.90 s | 1.98× |
| **OMP=4 @A76** | **4.03 s** | **3.88×**（并行效率 97%） |
| OMP=8（含 4×A55） | 4.60 s | 3.40×（**反降**） |

**J3 位级门 PASS**：`OMP=1` vs `=4` 输出**逐字节相同**。

> **教学点**：`interference_priority_rule`——**只用快核**。掺入 4×A55 反而更慢（与 K-EMB-001 §10 的 4→8 线程反降 0.8× 同现象）。

### M3 — 分块 MatMul（token 维批处理）

**先微基准**：`bench_mm.c` 实测 **GEMV 8.0 → 分块 MatMul（4 token × 2 行）12.1–13.2 GFLOP/s（1.51–1.66×）**、`max|Δ|≈0`。

**改动**：`lay_matmul` 4 token × 2 行分块（8 个 F32 NEON 累加器），让**权重行跨 4 token 复用、x 向量跨 2 行复用** ⇒ 内层 load:FMA 由 2:1 降到 **0.75:1**；按 token 块并行（各块写不同 Y 行 ⇒ 并行同序）。

**实测**：短 4.03 → **2.975 s（1.36×）**；长 22.35 → 15.412 s（1.45×）。**判据不同源、可叠加**：M4 省的是「同位置内发射密度」，M3 省的是「跨位置权重加载」。

**诚实披露（规约序）**：`lay_matmul` 每 (token,row) 用**单个**累加器按 k 块顺序累加，与 `lay_dot_f16` 的 4 累加器归约**顺序不同** ⇒ 严格非「数学逐位等同」，而是**输出级等同**（显示 4 位小数内无差异，远低于 J1 容差）。

### M5 — int8 dotprod（+ M5b/M5c/M5d）

**先微基准**：`bench_i8.c` 实测单 A76 核 **F16 7.2–7.6 → int8（per-32 块 scale，`vdotq_s32`）14.4–20.7 GFLOP/s（1.94–2.73×）**。

| 子级 | 改动要点 | 短 state | 增益 |
|---|---|---|---|
| **M5** | 载入时**按行**做 per-32 块对称量化（`scale=块maxabs/127`）→ `i8pool`+`qscpool`，释放 F16 blob；新增 `lay_dot_i8`（`vdotq_s32` 每指令 16 int8） | 2975→**1776 ms** | 1.68×；**RSS 879→535 MB** |
| **M5b** | `lay_matmul` 加 **t4r1** 分块（4 token × 1 行；微基准 t4r1 胜 t4r2，因 t4r2 16 累加器压力） | 1776→**1363 ms** | 1.30×（**与 M5 逐字节等价**） |
| **M5c** | `lay_quant_act` NEON 向量化（`vcvtnq_s32_f32` round-to-nearest-even，与标量 `lrintf` 位级同值）+ Wo/out_proj 也走分块 | 1363→**1322 ms** | 1.04×（**证伪「量化/线性层是 ~20% 大头」**） |
| **M5d** | **量化块 32→128**：`SCALE 块`与`vdotq CHUNK(恒32B)`分离，块末一次缩放 | 1322→**964 ms**（**321 ms/问**） | **1.37×**（本链最大单级） |

**M5d 的先验依据**：`bench_i8c.c` 实测**量化块 QBLK 的杠杆**：32→64 ≈1.5–1.6×、32→128 ≈**2.0–2.1×**、256/1024 边际递减。因为 **每块 scale 开销**（`vcvtq_f32_s32` + `vmlaq_n_f32` + 2 标量 load/mul，每 32 元素一次）与 `vdotq` 本征工作**同量级** ⇒ 摊薄它收益最大。

**质量门（M5 系列口径）**：int8 是**改变数值**的改动 ⇒ J1（5e-3 数值门）**不适用**，改以**决策输出等价**守门：`choice`/`urgency-argmax`/`noul` 三字段全不变（概率位移 ≤0.045）。

### M7 — 滑窗区间裁剪（保留）

**依据 M6 计时**：长 state 的 **attention 占 38%**（推翻了「attention 只占 ~2% FLOPs ⇒ 非瓶颈」的口算误判）。原 `attn_pos` 对**滑窗层仍扫描全部 n 个 key**，浪费 ~2×。改为只遍历有效区间 `[p-64, p+64]`（数学上**逐位等价**：被裁剪的 j 原取 `att=-1e30` ⇒ 贡献 0）。

**实测**：长 state attn 890 → 861 ms（~−3%，噪声内）。**关键判读**：收益小 ⇒ 长 state attention **不由滑窗层 key 扫描主导**，而是 **full 层（10/28 层，n²，不受裁剪）+ K/V 访存**主导。真正杠杆是 flash 式 Q-block（预计 ~1.1×，改动大，未做）。

## 3. 三次「证否回退」（本系列最密集）

| 实验 | 假设 | 实测 | 处置 |
|---|---|---|---|
| **M2b** 4 行寄存器分块 | x 复用降 load | **−27%** | 回退（16 NEON 累加器溢出） |
| **M6** 行块缓存复用 | MatMul 是 DRAM 受限（反算 427 ms 与实测吻合） | 短 state **−8%** | 回退（DRAM 假设被证否；matmul 实为 compute/load-port） |
| **M8** 双累加链 ILP | t4r1 单链 vdotq 串行依赖限发射 | 决策位级不变但**短 state −4.6%** | 回退（8 累加器寄存器压力 > ILP 收益） |

**M8 的结论**：**MatMul 内核在 A76 上已达「寄存器/发射」约束下的平衡点**——加 token 批（t8r1/t4r2）、加累加链、行块缓存**三种思路均实测证否/退化**。

## 4. 累计战绩与收口

| 阶段 | 短 state 3 问 | 长 state 3 问 | RSS |
|---|---|---|---|
| M0 基线（标量 F32） | 58.0 s | 294.9 s | 1.66 GB |
| M1（SIMD） | 14.23 s | 76.5 s | 1.66 GB |
| M2a（F16 存储） | 15.26 s | 81.1 s | **0.835 GB** |
| M4（+4 线程） | 4.03 s（14.4×） | 22.35 s | 0.841 GB |
| M3（+分块 MatMul） | 2.975 s（19.5×） | 15.412 s | 0.879 GB |
| M5（+int8） | 1.776 s（32.7×） | 11.189 s | **0.535 GB** |
| M5b（+int8 分块） | 1.363 s（42.6×） | 9.088 s | 0.534 GB |
| M5c（+向量化量化） | 1.322 s（43.9×） | 8.696 s | 0.536 GB |
| **M5d（+量化块 128）** | **0.963 s（60.2×）** | **~7.13 s（41×）** | 0.47 GB |

**单问延迟**：短 state **0.321 s/问**（目标 ≤0.3 s **达成**）；长 state ~2.38 s/问。**RSS 1.66 GB → 0.47 GB（−72%）**。

**质量门（收官）**：int8 QB=128 vs F16 基线 **32 请求 / 96 决策 100% 一致**；J3（OMP=1 vs 4）逐字节相同。

## 5. 本篇要点回收

| 教学点 | 内容 |
|---|---|
| 两段式瓶颈判断 | 先 compute（SIMD）后带宽（量化）；顺序错了就白做 |
| **先微基准、后实现** | M3/M5/M5b/M5d 全部先用板端微基准定量杠杆，再落地 |
| 归零上界 | M1 后算「48% 单核峰值」⇒ 判定 F32 SIMD 到顶，必须换维度 |
| **位级门 vs 决策门分离** | 逐位等价改动（M5b/M5c/M7/M8）用 `cmp` 逐字节；改变数值的（M5/M5d）用「决策三字段」守门 |
| 收益符号可反 | F16 提速为负（+7%）但 RSS −50% ⇒ 按「另一维度确定收益」保留 |
| **证否即回退** | M2b/M6/M8 三次实测退化均回退，不留复杂度 |
| 寄存器是硬约束 | 4 次撞墙（M2b / t4r2 / M8 / 以及向量模型与 YOLO）；**A76 上的实际平衡点** |
| 先测量再优化 | M6 计时器推翻口算误判，把方向从猜测改成数据驱动 |
| **A/B 陷阱** | `cp -p` 保留旧 mtime 会让 make 误判「无需重编」（首次 A/B 两臂 md5 相同即此坑）⇒ 必须 `touch`；小增益需**交替多轮**抵消热漂移 |

**残余（登记）**：attention Q-block（长 state ~1.1×，未做）；int4（A76 无 4-bit dotprod，不推荐）；与官方 `RLAgent` 直接对拍（本机 AV 不可用，以 M3==golden 为锚）；`/v1/systemone` 并发。
