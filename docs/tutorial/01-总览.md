# 01 · 总览：把三类模型接进自研推理引擎，并把它们优化到可用

> 系列教程 · 第 1 篇（兼系列索引）
> 后续：[02 向量模型·适配](02-向量模型-适配.md) ｜ [03 向量模型·优化](03-向量模型-优化.md) ｜ [04 Laya·适配](04-Laya-适配.md) ｜ [05 Laya·优化](05-Laya-优化.md) ｜ [06 YOLO·适配](06-YOLO-适配.md) ｜ [07 YOLO·优化](07-YOLO-优化.md)

本系列记录三件事：把**句子向量嵌入模型**、**非自回归决策模型**、**目标检测模型**接进自研推理引擎 `vLLM-Kestrel`（RK3588 板端），并逐一优化到「可用」。每一篇都是「**原理/方法（前半） + 实测数据与代码（后半）**」的结构——先讲清为什么这样做，再给出真实数字与复现路径。

---

## 1. 前提：这个引擎的三条红线

理解后续所有取舍，先要知道引擎的约束：

| 红线 | 含义 | 影响 |
|---|---|---|
| **自有格式 VQF** | 模型部署/运行时格式必须是引擎自有格式；**不引入 ONNX / `.rknn`** 作载体 | 「适配」= 写解析器把官方权重直接读成 VQF，不是调库 |
| **零第三方依赖** | 不链接 `librknnrt`、不依赖 torch/ultralytics 运行时 | 「加速」= 自己写 NEON/dotprod 内核、自己跟 NPU 驱动对话 |
| **板端优先** | 目标平台 RK3588（4×A76@2.256G + 4×A55@1.8G，NPU 3 核@1GHz） | 所有性能结论必须在板端实测，x64 仅为可编译/门禁 |

三条红线把「接一个模型」变成了一个**从权重解析到内核实现的全栈工程**。这也是本系列的价值所在。

---

## 2. 贯穿三个模型的同一套方法论

这是本系列最想传递的东西。三个模型形态迥异，但工程纪律完全一致：

### 2.1 先冻结判据，再采数

任何优化**在动手前**先写下判据（J1 数值等价 / J2 端到端等价 / J3 覆盖 / J4 回退透明 / J5 性能目标），并且**先算「归零上界」**——如果连「把这一项完全消掉」都解释不了目标差距，就直接否掉，避免无限投入。

> 例：向量模型优化里先反算「GEMM MAC 229.4 G-MAC ÷ 2.16 s = 106 GMAC/s」，才判定「追平官方」不可达、把目标收敛到「显著逼近」。

### 2.2 位级门与容差门**不互换**

- **算法等价变换**（并行化、预计算、循环重排）→ 必须**逐位一致**（`cmp` 逐字节 / md5 全等）。做了位级回归就不许用「容差」糊弄过去。
- **真正改变数值的改动**（量化、近似）→ 走**容差门或决策门**，并且**就地登记非位级性质**，说明口径。

> 例：Laya 优化里 M5b/M5c/M7（逐位等价）用 `cmp` 逐字节验证；M5/M5d（int8）用「决策三字段 96/96 一致」守门。

### 2.3 证否即回退（`nonmonotonic_benefit_no_cherry_pick`）

负结果和正结果同等重要。实测退化就**回退并登记**，不留复杂度。

> 例：Laya 的 M2b 寄存器分块 −27%、M6 行块缓存 −8%、M8 双累加链 −4.6%，三次都是「实测退化 → 回退」。YOLO 的「原生卷积标定」三轮用尽后回退 M2。

### 2.4 先测后优化（`bottleneck_scaling_attribution`）

瓶颈必须用**伸缩实验/探针**判别，不能靠口算猜。

> 例：向量模型用「纯读探针 + DRAM 屋顶标定」判别「带宽 vs 算力」，推翻了自己方案书里的反算（算术巧合）。Laya 的阶段计时器推翻了「长 state 非 attention-bound」的口算误判。

### 2.5 回退必须显式（`silent_fallback_false_pass`）

降级路径必须打日志、带计数、可辨识；**禁止「看似过了实为静默降级」**。

### 2.6 单一真源台账

每个专项 = 一份立项方案书（先冻结判据、逐级回填实测），外加 `落地台账.md` 变更日志。所有结论可回溯到某一行数据。

## 3. 公理库 → 工程映射（速查）

项目用一组公理约束优化决策。三篇里反复出现的：

| 公理 | 工程含义 |
|---|---|
| `collapse_to_classic` + `collapse_priority_rule` | **量化坍缩**：细粒度 per-block/per-channel scale；红线「≥16 元素量化粒度」（2-bit 单 scale 会乱码） |
| `conservation_law_under_collapse`（`confidence=0.65` 弱约束） | **精度守恒**：量化后排序/答案必须与 F32 golden 一致，且**必须实测**，不靠理论保证 |
| `isomorphic_superposition` | **结构同构**：卷积↔GEMM、全注意力↔滑窗点乘 |
| `interference_priority_rule` | **异构核调度**：只用快核（4×A76 / NPU3），掺入 A55 反而更慢（实测多次复现） |
| `feasibility_conclusion_timeliness` | **可行性先冻**：给尝试设上界，超界即回退 |
| `nonmonotonic_benefit_no_cherry_pick` | **证否即回退** |
| `silent_fallback_false_pass` | **回退透明** |
| `measurement_fairness_equivalence` | **公平 A/B**：同权重/同图/同后处理/同热态、同 governor、同绑核 |

## 4. 三个模型：总成绩

| 模型 | 形态 | 适配难点 | 优化前 → 后 | 质量门 |
|---|---|---|---|---|
| **Qwen3-Embedding-0.6B** | 句子向量（last-token + L2） | 引擎分词器**不是 BPE**（贪心最长前缀）⇒ 需换 byte-level BPE | prefill 位级不变、**−1.2%**（waste-skip）；判定达平台地板 | 分词 20/20 位级；E2E 余弦 0.994–0.997；检索 3/3 |
| **Laya**（ModernBERT-large + 决策头） | **非自回归**决策（不生成文本） | ModernBERT 交替注意力/双 RoPE/GLU-MLP + 决策头 + GPT-2 预分词复用 | 短 state 3 问 **58.0 s → 0.963 s（60.2×）**；RSS 1.66→0.47 GB | 决策 **96/96** 与 F16 golden 一致；OMP=1 vs 4 逐字节相同 |
| **YOLO**（v5 / v8 / v11） | 目标检测 | 自有 VQF v4 检测格式 + 一整条卷积前向 | NPU **≥5×**（v8 6.16–7.37×）；CPU int8 dotprod **~14×** | J1 数值 ≤5.1e-6；J2 242/247 配对、score ≤0.061、框 ≤9.8px |

三条曲线各有一个「反直觉点」，是本系列的看点：

1. **向量模型**：想省的 im2col 结果**不是带宽瓶颈**（纯读只要 39% 时间），真正卡在算力/发射——与直觉相反，且由此判定了「已达平台地板」。
2. **Laya**：F16 减半权重**在板端不提速**（+7%，因为已不是带宽受限），但 RSS 砍半值得保留；「寄存器分块」在 A76 上**三次实测退化**（16 个 NEON 累加器溢出）。
3. **YOLO**：**我们自己的 CPU 路径（~142 ms）反超我们自己的 NPU 路径（~232 ms）**——因为 NPU 路径走 im2col + 371 次提交/回读，而 CPU dotprod 把全部算力压在 A76 上、无提交开销。
