## 2. 来源与占比（实测，零代码改动）

来源 = K-PF-005 §11 的 MoE 分段归因（`VLLM_MOE_2B_SEG=1` 的 `[2BSEG-ARM]`，48 层合计）：

| 段 | 均值 (ms) | 占比 |
|---|---|---|
| `gu` | 26295.9 | 50.7% |
| **`dn`** | **23574.0** | **45.4%** |
| `tok`（串行前置） | 1873.2 | 3.7% |
| `cmb` | 119.9 | 0.2% |

- MoE 占 prefill 的 **96%** ⇒ dn ≈ **43.5% of prefill**、**~23.6 s / 48 层**。
- 严格归零上界（prefill）= `1/(1−0.435) ≈ 1.77×` —— dn 不可归零，故只作量级参照。

## 3. 可达上界（探针实测，工具 `tools/bench/l2_gu_probe.c`）

口径：`taskset -c 4-7`（4×A76）、governor=`performance`、`reps=3` 取最小；MAC 计数与内核同形。

| 形态 | 1 线程 | 4 线程 | 说明 |
|---|---|---|---|
| gu 忠实（对照） | 3.48 | **14.16 GMAC/s** | 同形双投影 |
| **dn 忠实**（`av` 按 (t,j) 散列，3 KB 跨距） | **0.86** | 3.53 | 引擎实态 |
| **dn · av 连续**（对照） | **3.61** | （≈14.4，按 4.1× 外推） | 计算上界 |

**推理**：

1. dn 的**内层形态本身与 gu 同级**（单核 3.61 vs 3.48 GMAC/s）⇒ 不存在"单投影天生慢"。
2. 但 **`av` 的访问局部性造成 4.2× 差**（散列 0.86 vs 连续 3.61）——**这是唯一显著敏感因子**。
3. 引擎 dn 实测 **6.05 GMAC/s**（4 线程，§2 的 dn 时间反算），落在「散列 3.53」与「连续 ≈14.4」之间 ⇒ 真实 `av` 局部性只是**部分**良好。
4. ⇒ **dn 的可达上界 ≈ 14.4 / 6.05 ≈ 2.4×**（4 线程口径）。折到 MoE：`51.86 → (26.30 + 23.57/2.4 + 0.12) = 36.2 s` ⇒ **MoE ≈1.43×**、prefill（96% 为 MoE）**≈1.40×**。

### 改动面（读实现后估）

- 目标内核 `arm2_dn_worker_exact`（[vllm_safetensors.c#L14951-L14980](../src/model/vllm_safetensors.c#L14951-L14980)），派发点 [#L15148](../src/model/vllm_safetensors.c#L15148)。
- 关键结构：`for cbi(24){ 解包 tile; for k(m){ 读 av[t*tk+j][cbi*32..+32] } }` —— `for cbi` 外层使**同一 (token,rank) 行的 3 KB 被 24 次非连续访问**，而 m 行之间跨距 = `ef×4 = 3 KB`。
- 候选方向（G1 前不选型）：① 交换 `k`/`cbi` 循环序（代价：解包次数 24→24×m，须实测权衡）；② `av` 按专家聚簇重排（代价：多一趟 gather）；③ 加大 tile 粒度。

## 4. 判定与敏感项

**PASS**（上界 ≈2.4× on dn，主因 `av` 局部性，且探针已给出 4.2× 的直接证据）。

| 敏感项 | 被否后结论如何变 |
|---|---|
| 「av 连续」对照（全 resident 同 16 行）是可达的 | 若真实可达只有部分改善 ⇒ 上界从 2.4× 降到 1.3–1.6×（仍 >1.3，仍应立项） |
| dn 时间反算的 MAC 口径（`nsel × d × ef`）正确 | 若口径错（如 dn 实算行数不同）⇒ 上界按比例重算 |
| 引擎 dn 的 6.05 不受 `gu` 段余温/缓存影响 | 若有 ⇒ 需按 §2 分段口径复核（分段已用同一计时器，风险低） |

## 5. 下一步（进 G1 须先冻结）

- 判据类型：**首选位级（A≡C）** —— 若只改循环序/预取，浮点累加序不变则位级；若累加序被迫改变 ⇒ 降级**容差 + 质量门**（ΔNLL ≤ +0.10、NIAH 5/5）。
- 口径：`[2BSEG-ARM]` 的 **dn 段**（比 `[PREFILL-KERNELS]` 更精确）+ 端到端 total；t4、governor 钉 `performance`、逐轮记 `mmcblk1` 读量并按**零缺页**筛选。
- 采样：同会话**交错 ≥3 轮**取中位；效应门 ≥ **5× 配对极差**。
- 逃生舱：新增 env 门（如 `VLLM_MOE_DN_ILV_ARM` / `VLLM_MOE_DN_ORDER`），**默认关**，走现状内核。
- 生效性凭证：打印实际生效的循环序/分块参数（否则踩 `silent_fallback_false_pass`）。
- 上界预登记：**dn −58%（=2.4×）**、MoE −30%、prefill −28% —— **不得当已实现收益**。

## 6. G1 判据冻结单（**先登记后采数**）

> 依据 `default_enablement_gate`：在任何代码改动与采数**之前**冻结判据，之后不得改判、不得挑数据点。

### 6.1 根因已定位（探针，governor=`performance`，4×A76）

在 §3 基础上补做**忠实任务序**对照（`av` 行集只依赖专家 e、跨 rg 复用 —— 与引擎同构）：

| dn 任务序 | 1 线程 | 4 线程 |
|---|---|---|
| `contig`（理论计算上界） | 3.76 | — |
| **`rg-major`**（引擎现状：`rg=idx/ne, e=idx%ne`） | **0.77** | **2.60 GMAC/s**（扩展比 3.40×） |
| **`exp-major`**（`e=idx/(d/4), rg=idx%(d/4)`） | 3.52 | **14.36 GMAC/s**（4.08×） |

⇒ **专家主序 / 行组主序 = 5.52×**（4 线程）。根因 = 行组主序下**每个 rg 都要把全部专家的 `av` 行（nsel×ef = 5.8 MB）重新流一遍**（512 个 rg ⇒ 每层 ~3 GB），而专家主序让同一专家的 m 行驻留、`av` 总流量降到 ~6 MB/层。

### 6.2 改动对象与候选

| 项 | 内容 |
|---|---|
| 目标内核 | `arm2_dn_worker_exact`（默认轨，[#L14951-L14980](../src/model/vllm_safetensors.c#L14951-L14980)）/ `arm2_dn_worker`（actq 轨在 **G2 一并镜像**） |
| 派发点 | `vllm_tp_parfor(0, ne*(d>>2), dn_worker, &ctx)`（[#L15148](../src/model/vllm_safetensors.c#L15148)） |
| **候选（唯一，最小面）** | 任务映射 `(rg,e)` → `(e,rg)`：`rg = idx / ne, e = idx % ne` **改为** `e = idx / (d>>2), rg = idx % (d>>2)`（循环体内其余一字不改） |
| 不选 | 交换内层 `k`/`cbi` 循环序（须重算解包次数，收益未证）；`av` 重排（多一趟 gather） |
| **负载均衡风险（已登记）** | 专家主序会重现 x86 注释（[#L13830-L13832](../src/model/vllm_safetensors.c#L13830-L13832)）的「高 m_e 长尾」；探针用**均匀 m=16**未建模 ⇒ 真实收益会被稀释。G2 若显示收益 < 预期，须加**交错分配**（按 m_e 排序后轮转装桶） |

### 6.3 冻结判据

| 项 | 冻结值 |
|---|---|
| **判据类型** | **位级（A≡C）**：只改任务映射/遍历顺序，每个 (token,rank) 的浮点累加表达式与 cb…序完全不变 ⇒ 必须逐字节一致 |
| **覆盖面/口径** | ① `[2BSEG-ARM]` 的 **dn 段**（比 `[PREFILL-KERNELS]` 精确）② 端到端 prefill total；`--stream-test --stream-ctx 246 --stream-n 2`，t4，**governor 钉 `performance`**，逐轮记 `mmcblk1` 读量并按**零缺页**筛选 |
| **采样** | 同会话**交错 ≥3 轮**（off/on/off…），取中位 |
| **效应门** | 差值 ≥ **5× 配对极差**（否则判噪声，不采纳）；**另记**「dn 段」的绝对值以供上界对照 |
| **生效性凭证** | 必须打印**实际使用的任务序**（如 `[MOEDNORD] dn order=exp-major`）；未启用时须打印 `rg-major`（否则踩 `silent_fallback_false_pass`） |
| **逃生舱** | 新增 env 门 `VLLM_MOE_DN_ORDER`（`0`/未设 = 现状 rg-major；`1` = exp-major）。**G2 默认关**，待 G3 通过由 G4 决定默认化 |
| **上界预登记** | dn **−58%（=2.4×）**、MoE −30%、prefill −28%（**探针 5.52× 为理想上界，不作预登记**） |

### 6.4 判定敏感项（冻结时登记）

| 假设 | 被否后结论如何变 |
|---|---|
| 探针的 5.52× 可部分迁移（探针用均匀 m=16，未含长尾） | 若长尾吃满 ⇒ 收益可能仅 −10~20%，仍 >0 但需加交错分配 |

| `av` 在 gu→dn 之间仍在缓存里（引擎实测优于模型的原因之一） | 若缓存余温显著 ⇒ 收益会被"提前吃掉"一部分 |

### 7.3 G3 效应（4 轮交错，零缺页，governor=`performance`，t4）

| 轮 | order | prefill total | gu（漂移标尺） | **dn 段** |
|---|---|---|---|---|
| 1 | exp-major | 42549.2 | 21965.0 | **16291.8** |
| 2 | rg-major | 50160.0 | 22450.9 | **23401.7** |
| 3 | exp-major | 43003.9 | 22342.0 | **16333.8** |
| 4 | rg-major | 52223.5 | 24267.2 | **23621.3** |

- **dn：−30.6%**（exp 16291.8/16333.8 vs rg 23401.7/23621.3）。
- **配对差 −7109.9 / −7287.5**（极差 **177.6**）⇒ 差值 7198.7 ≫ **5×177.6 = 888** ⇒ **过效应门**；方向一致率 **2/2**。
- **端到端 prefill：−16.4%**（42776.6 vs 51191.8）⇒ 端到端也过门（无口径张力）。
- 漂移校正：标尺 `gu`（本改动不触碰）exp 侧低 **5.2%** ⇒ 去漂移后 dn ≈ **−26.8%**（保守口径）。
- 对比 G0 预登记上界（dn −58%、prefill −28%）：实测约为上界的 **一半**，方向与量级一致，**未超预登记**。
